# Anaëlle Clef — Portfolio

Editorial interior-architecture portfolio. Static site — no build step.

## Pages
- `index.html` — home (cover, projects, experience, education, about, contact)
- `cbre.html`, `sedus.html`, `university.html`, `private.html` — project pages

All images, fonts and styles are inlined; every file opens directly in a browser.

## Put it online (free)
- **GitHub Pages:** repo Settings → Pages → Branch: this branch → `/root`. Live at the shown URL.
- **Netlify / Vercel:** drag-and-drop the folder, or connect this repo.
